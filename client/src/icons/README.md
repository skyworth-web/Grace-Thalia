# Extension Icons

This directory should contain three icon files for the Chrome extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create these icons using:
- Any image editor (Photoshop, GIMP, etc.)
- Online icon generators
- AI image generators

The icons should represent an interview/assistant theme. For testing, you can use simple colored squares or placeholder images.

## Quick Test Icons

For quick testing, you can create simple colored PNG files with the required dimensions. The extension will work without icons, but Chrome will show a default icon.
